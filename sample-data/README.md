# 통다 / Tongda bilingual sample pack

합성 사용 예시입니다. 실제 환자, 진단, 치료 지침, 효능 증거가 아닙니다. 사용자·인증정보와 사진은 없습니다.

## 시나리오

- 허리와 다리 / Lower back & leg: 오래 앉은 일상. 넓은 허리·왼쪽 허벅지 표시에서 좁은 허리·오른쪽 허벅지 표시로 달라집니다. 공통 부위와 이동 부위가 기간 비교에 보입니다.
- 목·어깨 / Neck & shoulders: 책상 작업 뒤 느낌. 목은 공통이며 어깨의 좌우·범위·강도가 날짜에 따라 달라집니다.
- 활동 후 무릎 / Knee after activity: 산책·계단이 있었던 날과 조용한 날. 무릎 앞쪽과 인접 허벅지 표시가 달라집니다.

84일 계획(기준일 −83일부터 기준일까지)에 기록 없는 날을 포함합니다. 실제 첫 기록은 기준일 −82일입니다. 언어별 통증 146건, 처치 55건, 3개 이슈. 각 이슈에 그림 기록 37~38일, 복수기록일 11~12일, 전체 782개 실제 DrawingPath 획이 있습니다. 모든 통증 기록에 그림이 있으며 한 점 경로는 없습니다. 획별 강도는 앱 색상으로 재생되고 기록 강도는 획별 최고 강도입니다. 범위·굵기·부위와 강도는 시간에 따라 변합니다. 걷기·스트레칭·휴식 기록은 활동 예시이며 변화의 원인으로 해석하지 않습니다.

## 파일

- `fixture-ko.json`, `fixture-en.json`: 날짜 오프셋·시각·메모·증상·처치·실제 획 좌표를 읽을 수 있는 원본. 두 언어는 동일한 시나리오/시각/그림/수치를 사용합니다. 사용자 노출 이름·메모·증상·처치 항목은 각각 한국어/영어입니다. 영어 fixture는 영어로 읽을 수 있으며, 실제 native payload의 기본 증상·처치 항목은 앱 규약상 한국어 식별자로 저장됩니다. 앱의 CatalogLocalization이 영어로 표시하고 편집 화면에서도 선택을 유지합니다. 자유 입력 이름·메모는 영어 그대로입니다.
- `tongda-sample-ko.json`, `tongda-sample-en.json`: 기준일을 적용한 BackupSchema `native-v2`, version 2 payload.
- `tongda-sample-ko.tngd`, `tongda-sample-en.tngd`: 생성기가 만든 실제 TNGD. 확장자만 바꾼 JSON이 아닙니다.
- `app-export-ko.tngd`, `app-export-en.tngd`: 해당 샘플을 앱에서 가져온 후 **앱 자체 데이터 내보내기**로 저장한 파일. 다시 앱으로 가져오기도 확인했습니다.
- `verification.json`: 획·그림 날짜·강도·body mask 및 앱 export 내용 일치 검사 결과. ID 재할당과 export 시각을 제외하고 이름·타임스탬프·그림·강도·메모·증상·처치가 일치하는지 검사합니다.

TNGD는 앱 `BackupRepository`와 같은 `TNGD` magic + version 1 + 16-byte salt + 12-byte IV + AES-256-GCM ciphertext/tag, PBKDF2-HMAC-SHA256 100,000회 형식입니다. 앱의 공개 호환 규약상 보호는 제한적이며 개인 데이터 보호용 암호 체계로 의존하면 안 됩니다.

## 날짜를 최신으로 갱신

Python 3와 `cryptography`가 필요합니다. 검증에는 `Pillow`도 사용합니다.

```sh
cd tongda-manual
python3 sample-data/generate.py                 # 오늘, Asia/Seoul 기준
python3 sample-data/generate.py --date 2026-09-09
```

`--init`은 시나리오 정의로 원본 fixture를 다시 만듭니다. fixture를 직접 편집했다면 이 옵션을 사용하지 마세요. 기본 실행은 원본의 날짜 오프셋을 유지하고 `tongda-sample-*.json/.tngd`만 갱신합니다. `app-export-*`는 검증한 2026-09-09 기준 원본으로 보존되므로 날짜 갱신 후 새 앱 export를 받아야 비교 검증이 다시 통과합니다.

## 앱 가져오기 / 내보내기

1. 설정 → 언어에서 한국어 또는 English를 고릅니다. 앱 언어를 바꾸는 것만으로 이미 저장한 자유 입력 텍스트가 번역되지는 않습니다.
2. 해당 언어의 `.tngd`를 기기에 복사하고 설정 → 데이터 가져오기에서 선택합니다.
3. 촬영 전용 테스트 기기에서는 **전부 교체 / Replace All**로 복원합니다. 개인 기록이 있는 기기에서는 먼저 백업하세요. 전부 교체는 기존 기록과 사진을 지웁니다. 합치기는 기존 데이터를 유지하지만 반복 가져오기 시 중복 샘플이 생깁니다.
4. 3개 통증·146개 기록·55개 처치라는 완료 메시지, 이름, 홈 바디맵, 통계에서 분석할 통증을 확인합니다.
5. 설정 → 데이터 내보내기로 앱 자체 `.tngd`를 저장합니다. 파일을 가져오기에서 다시 선택해 복원을 확인할 수 있습니다.

무료에서는 현재기간 요약을 확인할 수 있습니다. 직전기간 비교·직접 지정 촬영은 기존 debug/internal-test 강제 프리미엄 기능을 사용했으며 실제 결제하지 않았습니다. 일반 사용자의 구매 상태를 샘플이 바꾸지는 않습니다.

사진은 TNGD에 포함되지 않습니다. 이번 핵심 예시는 통증 바디맵과 처치 기록만 사용합니다.
